Đổi Nhạc & Xuất Thiệp Trên ĐT

1. Cách Đổi Ảnh Nhanh Nhất Trên Điện Thoại

Chỉ cần đóng bảng này lại và chạm ngón tay trực tiếp vào bất kỳ bức ảnh nào trên thiệp (có nhãn 📷 Chạm để đổi ảnh). Điện thoại sẽ mở ngay Thư viện Ảnh của bạn, tự động nén nhẹ và lưu ngay trên máy!

2. Nhạc Nền Bài Hát "Lễ Đường - Kai Đinh"

Mặc định thiệp đã phát sẵn bản hát có lời Lễ Đường - Kai Đinh. Nếu muốn dùng file .mp3 riêng trong điện thoại:

3. Lấy Thiệp Đi Gửi Khách (Không Cần Tạo Folder)

Mọi bức ảnh bạn vừa chọn từ điện thoại đã được gắn thẳng vào bên trong 1 file index.html duy nhất. Bạn không cần tạo thư mục assets/ hay sửa code gì cả!

💡 Mẹo đưa lên mạng bằng điện thoại trong 30 giây: Sau khi tải file index.html này về điện thoại, bạn mở trang tiiny.host hoặc app.netlify.com/drop trên điện thoại, tải đúng 1 file này lên là có ngay đường link web gửi qua Zalo!
